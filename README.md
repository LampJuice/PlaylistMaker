# 🎵 PlaylistMaker

Android-приложение для поиска музыкальных треков с использованием iTunes API.

Проект был создан в рамках обучения Android-разработке и демонстрирует использование современной архитектуры приложения, работу с сетью, локальным хранением данных и обработкой состояний пользовательского интерфейса.

## ✨ Возможности

- 🔍 Поиск музыкальных треков
- 🎵 Просмотр информации о треке
- 🕘 История поиска
- ❤️ Добавление треков в избранное
- 📂 Создание и управление плейлистами
- 💾 Локальное хранение данных
- 🌐 Работа с REST API
- ⚡ Асинхронная загрузка данных

## 🏗 Архитектура

Проект построен с использованием принципов **Clean Architecture** и паттерна **MVVM**.

Структура проекта разделена на слои:

- Presentation
- Domain
- Data

Такой подход позволяет разделить ответственность между слоями, упростить поддержку приложения и облегчить тестирование.

---

## 👨‍💻 Что реализовал

В рамках проекта самостоятельно разработал:

- реализацию поиска треков через REST API;
- пользовательские экраны;
- навигацию между экранами;
- обработку состояний загрузки, ошибок и пустых результатов;
- локальное хранение данных;
- работу с Coroutines и Flow;
- архитектуру приложения на основе MVVM и Clean Architecture.

## 🚀 Как запустить проект

1. Клонировать репозиторий

```bash
git clone https://github.com/LampJuice/PlaylistMaker.git
```

2. Открыть проект в Android Studio.

3. Выполнить синхронизацию Gradle.

4. Запустить приложение на эмуляторе или устройстве.
